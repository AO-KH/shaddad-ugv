# Decision record: D-<NNN> <short title>

A decision record is one entry of the project's decision log (NASL-EMS-HBK-001 section 8.2). Keep it short. The decision log is the list of these entries, in order (for Shaddad: the decisions table of `docs/architecture.md`).

Table 1. The decision.

| Field | Content |
|---|---|
| ID and date | D-<NNN>, <YYYY-MM-DD> |
| Decided by | <the owner / the lead / a subsystem lead>, for <a gate / a change request / a card> |
| Context | <the situation and the question, in two or three sentences> |
| Options | (a) <option> - <consequence>; (b) <option> - <consequence>; (c) ... |
| Decision | <the option chosen>; the owner's words when the owner decided: "<word for word>" |
| Reasons | <why this option> |
| Consequences | <what changes: requirements, interfaces, cards, tests, risks; what is accepted> |
| Supersedes | <D-numbers it replaces, or none> |
| References | <card, CR, report, analysis> |
